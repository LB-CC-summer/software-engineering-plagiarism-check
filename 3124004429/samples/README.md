# 样例数据说明

`samples/` 是课程下发的六份测试文本的 UTF-8 清理版本：

- `orig.txt`：原文。
- `orig_0.8_add.txt`：增加内容后的版本。
- `orig_0.8_del.txt`：删除部分内容后的版本。
- `orig_0.8_dis_1.txt`：轻度打乱顺序后的版本。
- `orig_0.8_dis_10.txt`：中度打乱顺序后的版本。
- `orig_0.8_dis_15.txt`：较强打乱顺序后的版本。

原始下载文件中的 `del` 和 `dis` 文件是浏览器保存的 GitHub HTML 页面。
程序能够自动识别这种页面并提取正文，清理后的文本仅用于仓库内可重复测试。
