# 单元测试与异常处理报告

## 1. 测试策略

项目使用 `pytest`，覆盖以下四类场景：

1. 正常功能：完全一致、增删改、同义改写、语序打乱。
2. 边界条件：空字符串、单字符、超短文本、全角字符。
3. 文件行为：UTF-8 BOM、GB18030、缺失文件、目录代替文件。
4. 命令行行为：参数数量错误、解码错误、输出路径错误。

测试总量为 44 个，分支覆盖率为 100%。

## 2. 代表性测试用例

| 用例 | 构造数据 | 断言目标 |
| --- | --- | --- |
| 完全相同 | 两篇完全一致的文本 | 分数为 `1.00` |
| 完全为空 | 空原文和空抄袭版 | 分数为 `0.00` |
| 完全不同 | 两个无关主题 | 分数低于 `0.20` |
| 增加内容 | 原文后追加新段落 | 分数不低于 `0.65` |
| 删除内容 | 删除原文部分句子 | 分数不低于 `0.65` |
| 打乱语序 | 调换句子顺序 | 分数大于 `0.40` |
| 同义改写 | 星期天/周天、晴/晴朗 | 分数大于 `0.50` |
| 对称性 | 交换原文和抄袭版 | 两次结果近似相等 |
| 全角字符 | `ＡＢＣ１２３` | 归一化为 `abc123` |
| HTML 页面 | GitHub blob 表格行 | 只提取正文 |
| 覆盖率 | 44 个测试 | 分支覆盖率 100% |
| 性能 | 课程样例 | 单次计算小于 1 秒 |

## 3. 异常设计

| 异常 | 设计目标 | 测试场景 | 处理结果 |
| --- | --- | --- | --- |
| `CommandLineError` | 参数数量必须是 3 | 只传 1 个路径 | 输出 usage，退出码 2 |
| `DocumentReadError` | 输入必须是存在的文件 | 缺失路径、目录路径、读取失败 | 输出明确错误，不写答案 |
| `DocumentDecodeError` | 支持常见中文编码，拒绝损坏 BOM | UTF-16 BOM 损坏、不支持编码 | 输出解码错误，退出码 2 |
| `AnswerWriteError` | 输出必须可写 | 将目录作为答案文件 | 输出写入错误，退出码 2 |

## 4. 覆盖范围评价

当前测试不仅覆盖了正常算法路径，也覆盖了三个 n-gram 阶数的分支、
空向量的余弦相似度、零权重配置、HTML 提取、编码回退和所有异常出口。
因此 44 个测试足以满足本程序的功能与异常测试要求。
