## 估算说明

首次接触该题目时，我会选择 Python 标准库实现字符 n-gram 相似度算法。
主要风险包括：

1. 中文文本没有天然空格，需要避免依赖英文分词。
2. 增删改会使字符级精确匹配失效，需要设计多阶 n-gram 融合策略。
3. `difflib.SequenceMatcher` 的复杂度可能无法满足 5 秒限制。
4. 需要同时处理文件不存在、编码错误、输出路径错误等异常。
5. 需要补足至少 10 个单元测试，并达到较高分支覆盖率。

估算时间在编码开始前写入本文件，并作为第一次 Git 提交的一部分保存。
实际耗时在功能、测试、优化和报告全部完成后补齐。
